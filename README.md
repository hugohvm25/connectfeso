# connectfeso

Bem vindo ao Connect Feso.

Faça um Tour pelos campus do UNIFESO.

Para a implementação do projeto altere a dependendcia no arquivo pubspec.yaml com as informações abaixo

dependencies:
flutter:
sdk: flutter
http: ^0.13.5
flutter_spinkit: ^5.1.0  # Animação de carregamento

depois rode no terminal para atualizar

# flutter pub get
